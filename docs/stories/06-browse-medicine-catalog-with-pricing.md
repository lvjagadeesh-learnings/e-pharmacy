# User Story: 06 — Browse the medicine catalog with pricing

**Status:** ready

**As a** shopper,
**I want** to see a list of available medicines with their prices,
**so that** I can decide what to buy.

## Acceptance Criteria

- [ ] A catalog page lists medicines with name, price, and (if available) a short description/image
- [ ] The list loads from a backend endpoint rather than being hardcoded in the frontend
- [ ] Loading and empty-catalog states are handled
- [ ] Prices are displayed in a consistent currency format

## Notes

- Search, filtering, and categories were not requested — out of scope for this story; candidate follow-up.
- Requires a backend medicines/products endpoint that does not yet exist; that build-out belongs in this story's implementation plan.
